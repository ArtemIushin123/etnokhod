# Этноход (бывш. «Карта народов») — контекст проекта

Отвечай на русском. Я Артём, в команде отвечаю за техническую часть и бэкенд.

## Что за проект

Образовательная веб-игра для чемпионата (направление «Интерактивные и мультимедийные форматы», тема чемпионата связана с ИИ). Игрок путешествует по карте России, открывает регионы и знакомится с культурой народов: узоры, кухня, праздники и обычаи, легенды. Стартовый регион — Башкортостан.

Игровой цикл: вход по коду класса → выбор героя → карта → проводник-персонаж региона → 4 раздела о культуре → тест (5 заданий, проходной балл 4) → награда (элемент костюма + значок) → открывается следующий регион.

## Целевая аудитория (решено)

- Основная: школьники 5–9 классов, 10–15 лет. Играют со смартфона. В 5–6 классах проходят ОДНКНР.
- Вторичная: учителя (ОДНКНР, история, литература, классные руководители), школы, региональные министерства.
- Третья: родители (в будущем плательщики, в MVP платежей нет).

## Ключевые решения (не менять без обсуждения)

- Сначала знакомство, потом тест.
- Mobile-first, в полной версии PWA.
- Дети не вводят личные данные: учитель создаёт класс, ученик входит по коду класса и нику (без имени, email, телефона). Причина — 152-ФЗ, данные детей до 14 лет.
- Кабинет учителя: прогресс класса, ошибки по темам, связь с темами ОДНКНР 5 класса, сценарий занятия на 15 минут, переключатель свободного чата с ИИ.
- ИИ-проводник: отвечает от лица персонажа по проверенным материалам (схема RAG), фильтр вопросов и ответов, не спрашивает личные данные, учитель может оставить только готовые вопросы, лимит 10 вопросов в день на ученика.
- Модели: российские (GigaChat или YandexGPT) через собственный сервер-прокси. Ключи API никогда не попадают во фронтенд.
- Бэкенд полной версии: Go (Gin или Echo, pgx) + PostgreSQL, хостинг в РФ (Yandex Cloud / VK Cloud / Selectel).

## Текущий прототип: index.html

Один файл HTML + CSS + JS без фреймворков и сборки плюс папка `assets/` с картинками (WebP, ~1,4 МБ). Открывается двойным кликом, публикуется на GitHub Pages — `index.html` всегда вместе с `assets/`. Шрифты — Google Fonts (PT Sans, Ruslan Display).

Визуал (с 01.10.2026): арт команды. Исходники художника лежат в `refs/` (тяжёлые PNG, на сайт не нужны), из них скрипт `tools/assets/build_assets.py` делает `assets/`: фоны экранов (`bg-main` — вход/герой/учитель, `bg-map`, `bg-bashkortostan`, `bg-chat`), 4 героя `hero-<m|f>-<dark|light>`, шапка `hat-burek`, Данияр `guide-daniyar`, монеты-награды `coin-*`, лого/фавикон, рамки реплик `bubble-guide` и `bubble-chat` (через `border-image`, режутся на 9 частей). Палитра в `:root`: #4B0082, #A52A2A, #DAA520, #FFEBCD, #6495ED (зелёный — только «верно/пройдено»). Форму кнопок не менять — указание команды.

Структура скрипта (разделы помечены комментариями `=====`):

1. **КОНТЕНТ** — `MAP` (точки регионов на карте, `x`/`y`, `side` для подписи: l, r, t, b; для мелких регионов `callout:{x,y}` — значок выносится в сторону с пунктирной линией, как у Крыма), `DEMO_CLASS` (демо-класс, код `KN-5B`), `ODNKNR` (связь разделов с темами программы), `REWARDS` (с картинкой `img`), `HEROES` (пол × цвет волос; `hat` — посадка бурека в % от картинки героя), `REGIONS` (весь контент региона: `guide` с `img`, `intro`, `learn`, `quiz`, `passScore`).
2. **ИИ-ПРОВОДНИК** — `AI_PROXY_URL` (пусто = заготовленные ответы), `GUIDE_PROMPT`, `GREETING`, `CANNED` (ответы по ключевым словам), `FALLBACK`, `SUGGESTIONS`, `RUDE_REPLY`. Там же фильтр грубых слов `isRude()` (правила `RUDE_RU`/`RUDE_EN`): проверяет ник при входе, сообщения в чат (грубое скрывается и не уходит нейросети) и ответы нейросети. Ловит латиницу-двойники, цифры, транслит, «х.у.й», повторы букв; корни привязаны к началу слова, чтобы не задевать «психую», «хлебало», «себе». После правок правил прогонять на списке грубых и обычных слов.
3. **ГРАФИКА** — SVG-знаки орнамента в `G` (diamond, horns, sun, heart, wave, kurai), `avatar(пол, волосы, шапка, высота)` — картинка героя с буреком поверх, `guideImg()`, `medallion()` (лого), `coin()` (монета награды).
4. **СОСТОЯНИЕ** — прогресс в `localStorage`, ключ `karta-narodov-proto-v1` (старое имя оставлено, чтобы не терять прогресс; `hero` — пол, `hair` — цвет волос). Сайт всегда открывается с главного экрана; если ученик уже входил, там кнопки «Продолжить» и «Войти другим учеником».
5. **ОТРИСОВКА** — экраны: `rStart` (вход), `rHero` (выбор героя и цвета волос), `rTeacher` (кабинет учителя), `rMap` (карта), `rProfile` (кабинет ученика: награды, статистика, регионы; вход — кнопка-аватар с ником в шапке; героя после выбора сменить нельзя), `rRegion` (проводник, разделы, тест, результат, награда). Фон экрана задаёт `render()` через `body[data-bg]`. Крупные элементы (Данияр, герои, лого, карта) масштабируются от высоты окна (`vh` в CSS), чтобы игровые экраны на ноутбуке помещались без прокрутки.
6. **ДЕЙСТВИЯ** — `activate()` по атрибуту `data-act`, отправка формы входа.
7. **ЧАТ** — открытие, режим «только готовые вопросы» (`S.chatFree`), запрос к прокси или заготовленные ответы.

Правка контента = правка объектов в разделе 1 и 2, логику трогать не нужно. Новый регион = новый блок в `REGIONS` + точка в `MAP` + контур в `RU_MAP.regions` (`tools/map`, регион может состоять из нескольких субъектов) + проводник и фон в `assets/`. На карте 6 регионов: Башкортостан (открыт), Татарстан, Дагестан, Тыва, Якутия, Крым (Республика Крым + Севастополь).

## ВАЖНО: тексты про Башкортостан

Все тексты региона (реплики проводника Данияра, 4 раздела, тест, пояснения, награды, ответы чата) взяты **строго** из утверждённого командой документа. Не переписывать, не «улучшать» и не добавлять факты без прямой просьбы. Варианты ответов в тесте стоят в порядке из документа (без перемешивания).

Известные вопросы к тексту (решает команда, не я):
- «куштанаш»: в словарях башкирский гостинец — «күстәнәс» (кустанас).
- В реплике 3 сказано, что тест будет «перед» знакомством, а в игре тест после.
- Куштанаш есть в тесте, но объясняется только в приветствии.
- Проводник говорит «ты», интерфейс — «вы».
- Задание 1 теста по просьбе Артёма (01.10.2026) переделано: было «собери полоску по образцу», стало «подбери знак к названию узора» (тип `match`: Ромб, Кускар, Солнце, Сердечко + лишний знак «Бегущая волна»). Реплика, заголовок и пояснение задания переписаны под новую механику по фактам из раздела «Узоры» — команде сверить с документом.
- Чат отвечает про бешбармак, губадию, курут, которых нет в разделе «Кухня».

## Как проверять изменения

После правок JS проверять синтаксис (например, вынести содержимое `<script>` и прогнать `node --check`) и пройти сценарий целиком: вход (код `KN-5B`) → герой и цвет волос → карта → Башкортостан → 4 раздела → тест → награда (бурек на герое) → чат (и грубое сообщение) → кабинет ученика → кабинет учителя. Плюс попытка войти с грубым ником. Смотреть и на ширине телефона (~390 px), и на десктопе.
